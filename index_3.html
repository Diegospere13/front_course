Os Ids servem para dar um nome único a esse elemento, permitindo que ele seja referenciado de forma específica no código.

Cabeçalho 2

As classes também são identificadores de elementos, porém diferente dos Ids, as classes podem ser repetidas em vários elementos, e cada elemento pode ter mais de uma classe também a depender do que se deseja faze com elas. Esse tipo de identificador é muito importante para quando for utilizar o CSS e o JS no seu código.
